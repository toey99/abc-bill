# ABC Bill — ใบแจ้งหนี้ / บิลเงินสด

โปรแกรมออกใบแจ้งหนี้ (Invoice) และบิลเงินสด (Cash Sale) ของ ABC : Alliance Border Consulting
รองรับ 2 สกุลเงิน (THB / CNY) ใช้งานจากเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

**ใช้งาน:** https://toey99.github.io/abc-bill/

## เลขที่เอกสาร (ออกอัตโนมัติ)

- ใบแจ้งหนี้: `INV-YYYYMMDD` + เลขรัน 4 หลัก เช่น `INV-202606110001`
- บิลเงินสด: `CS-YYYYMMDD` + เลขรัน 4 หลัก เช่น `CS-202606110001`
- วันที่ยึดตามช่อง "วันที่" ในบิล (เลือกจากปฏิทิน)
- เลขรันนับแยกต่อวัน/ต่อประเภท เริ่ม 0001 ใหม่ทุกวัน
- เมื่อกด "พิมพ์เอกสาร" เลขนั้นจะถูกบันทึกว่าใช้แล้ว บิลถัดไปของวันเดียวกันจะได้เลขถัดไป
- กดปุ่ม ↻ ข้างเลขที่เอกสาร เพื่อขึ้นเลขถัดไปทันที

> เลขรันเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเครื่อง เลขจะเริ่มนับใหม่

## ลูกค้าหลายคนใน 1 บิล

- กด "+ เพิ่มลูกค้า" ได้สูงสุด 5 คน (ชื่ออังกฤษ / ชื่อจีน / พาสปอร์ต ต่อคน)
- 1 คน: แสดงชื่อและพาสปอร์ตที่หัวบิลเหมือนเดิม
- 2 คนขึ้นไป: หัวบิลแสดงตาราง "รายชื่อลูกค้า" (ลำดับ / ชื่อ / พาสปอร์ต) ตารางเดียว ส่วนรายการค่าบริการระบุจำนวนท่านแทน ไม่แสดงรายชื่อซ้ำ
